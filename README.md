# Noted

A free, minimal, pure-black markdown editor for Android, Windows, macOS and Linux.

- Notes are plain `.md` files in a folder you choose. Point any sync app at it.
- Keep-style grid of notes and folders, pins, and drag to reorder.
- Notes open in reading mode, with foldable headings and tickable checkboxes.
- Live-preview editing: markdown syntax only shows on the line you're editing.

Download the latest build from [Releases](https://github.com/senseldeez/noted/releases).

| Folder | What |
|---|---|
| `app/` | Android app (Kotlin, Jetpack Compose). `./gradlew assembleRelease` |
| `desktop/` | Desktop app (Rust, egui). See [desktop/README.md](desktop/README.md) |
